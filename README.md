# Sky Cat Cafe V31.2

가상 카페 웹사이트 포트폴리오. V31의 기능을 유지하며 굿즈샵 51종의 상품 이미지 영역을 개선한 버전입니다.

## V31.2 굿즈샵 변경

- 51종 원본 사진의 상품 중심 검토 및 치우친 위치 개별 보정
- 상품 카드와 상세 팝업에 동일한 상품별 이동값 적용
- 모바일에서도 동일한 중심 유지
- 기존 배경, 원본 사진 및 구매 기능 유지

V31.1에서 업데이트할 때는 `goods.css`만 교체하면 됩니다.

## V31.1 굿즈샵 변경

- 캐릭터별 배경 색상 및 별·하트·구름·달 장식 적용
- 상품 종류별 배경 패턴 적용
- 51종 상품을 정사각형 전시 영역 중앙에 배치
- 상품 상세 팝업에도 동일한 테마 적용
- 원본 상품 이미지와 상품명, 가격, 구매 기능 유지

V31에서 업데이트하는 경우 `goods.html`, `goods.css`, `goods.js` 세 파일만 교체해도 됩니다.

## 실행

- `index.html`: 랜딩 페이지
- `index(order).html`: 공식 홈페이지와 주문·예약·고객 서비스
- `goods.html`: 굿즈샵
- `admin.html`: 관리자 화면 (공개 시연/로컬 테스트 및 설정된 서버 인증)

ZIP을 풀고 같은 폴더 안의 파일을 유지하세요. HTML 직접 열기는 화면 확인용으로 지원하지만, 사이트 간 저장소 연동 및 외부 서비스 검수에는 HTTP/HTTPS에서 실행하는 것을 권장합니다.

## 기존 설정 보존

기존에 EmailJS를 연결했거나 관리자 시연 설정을 직접 수정했다면 **기존 설정 파일을 백업하고 유지**하세요.

- `emailjs-config.js`
- `admin-test-config.js`
- `supabase-config.js`

이 배포본의 설정 파일은 V30.2 원본과 동일합니다. 사용자의 실제 연결 값이 별도로 설정된 경우 기존 값을 덮어쓰지 마세요.

GitHub Pages에 올릴 때는 HTML, CSS, JS 및 assets를 동일한 배포 폴더에 업로드하세요. 기존 주소와 파일명을 유지합니다. 업로드 후 Ctrl+F5로 새로고침하세요.

실제 결제·배송·매장 예약 서비스는 제공하지 않습니다. 공개 관리자 시연 로그인은 실제 보안 인증이 아닙니다. 실제 개인정보나 운영 계정 비밀번호를 입력하지 마세요.
